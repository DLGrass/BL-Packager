Bilup Packager

本地打包器

把 Scratch 3 作品打包成单文件 HTML，或带 WebView2 宿主的 Windows 可执行文件——两种产物用的是同一条打包管线。

  • 零依赖：只用 Node 内置模块，不需要安装任何第三方包。
  • 不上传：打包本身不需要联网，作品不会离开这台电脑。
  • 同一条管线：两个 CLI、本地网页版和在线版都走 src/lib/pipeline.js，改一处三处同步。

本项目与 Scratch、Scratch 团队、Scratch 基金会无关。

云变量

「存储在本地」会把 ☁ 变量的值写进浏览器的 localStorage，并在作品打开时恢复； 同一个浏览器里打开多个窗口，改动会在窗口之间同步。存储键以「作品 ID」区分，所以下面这一项要填得具体一些。

上游的默认做法是连到 clouddata.turbowarp.org 与其他玩家实时同步， 那需要联网，因此本机版只提供本地存储这一种模式。

本打包器专用

BLPK 是本打包器自己的容器：条目会按测量结果选择性压缩，装入时直接交出素材视图、不再走一遍解压。 tw 保留上游策略，用来做 A/B 对照。

像素完全不变，只把 PNG 的行滤波与 deflate 流重新编码一遍。Scratch 造型是画布 toDataURL() 的产物，这一步通常能省下两位数百分比的体积。

只在测量到的收益不足 5% 时才逐个压缩；勾上这一项就一律原样存放。

预热素材会在作品开始运行前先把造型与声音解码进内存，代价是打开时要多等一小会儿。
