BL Packager

本地打包器

把 Scratch 3 作品打包成单文件 HTML，或带 WebView2 宿主的 Windows 可执行文件。

打包全程在 127.0.0.1 上的本进程里完成，作品不会离开这台电脑，也不需要任何联网功能。

本项目与 Scratch、Scratch 团队、Scratch 基金会无关。

选择作品

选择一个 .sb3 作品文件，也可以直接把它拖到这张卡片上。

高级选项

像素完全不变，只把 PNG 的行滤波与 deflate 流重新编码一遍。Scratch 造型是画布 toDataURL() 的产物，这一步通常能省下两位数百分比的体积。

只在测量到的收益不足 5% 时才逐个压缩；勾上这一项就一律原样存放。
